# Changelog

## 2.1.1

- Fixed duplicate slash commands caused by simultaneous global and guild registrations.
- Command deployment now removes legacy global commands before synchronizing the configured DevForge server.
- Added deployment verification and clearer refresh guidance for Windows users.

## 2.1.0

- Added Developer Passport with verified activity signals.
- Added stack-aware opportunity discovery for projects and code reviews.
- Added automatic private project workspaces with team roles, text hubs, and voice rooms.
- Added Project Health Score and guarded Project Rescue campaigns.
- Added deterministic health and matching tests while preserving existing data and commands.

## 2.0.0

- Preserves every DevForge 1.0 command and SQLite table.
- Adds 58 modular feature groups and expands the registry to 74 English slash commands.
- Adds advanced moderation, tickets, onboarding, role menus, analytics, developer profiles, skill trees, achievements, Reputation 2.0, mentoring, bounties, review matching, events, challenges, productivity tools, internal credits, and server automation.
- Adds signed GitHub event routing, release feeds, SSRF-protected uptime monitoring, recurring reminders, scheduled stand-ups, digests, and temporary voice rooms.
- Adds per-server module switches, a command permission matrix, notification preferences, audit history, and an optional token-protected administration dashboard.
- Adds additive v2 database migrations, a plugin registry, new tests, and a safe v1-to-v2 migration guide.

## 1.0.0

- Initial DevForge release for developer communities.
