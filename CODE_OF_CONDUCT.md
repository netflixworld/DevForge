# Community code of conduct / Código de conduta

## English

DevForge welcomes developers of all experience levels. Be respectful, explain technical feedback constructively, credit other people's work, and protect private information. Harassment, threats, hate speech, unsolicited promotion, and sharing someone else's private data are not welcome.

Report community problems to server moderators. Report repository problems through an issue when they can be discussed publicly. For security or privacy concerns, contact the maintainers privately as described in [SECURITY.md](SECURITY.md). Moderators and maintainers may remove content or restrict participation to protect the community.

## Português

O DevForge recebe developers de todos os níveis. Respeite as pessoas, explique feedback técnico de forma construtiva, dê crédito ao trabalho alheio e proteja dados privados. Assédio, ameaças, discurso de ódio, divulgação insistente e exposição de dados pessoais não são aceitos.

Leve problemas da comunidade aos moderadores do servidor. Problemas públicos no repositório podem ser relatados por issue. Para segurança ou privacidade, fale em particular com os responsáveis conforme [SECURITY.md](SECURITY.md). Moderadores e mantenedores podem remover conteúdo ou restringir participação para proteger a comunidade.
